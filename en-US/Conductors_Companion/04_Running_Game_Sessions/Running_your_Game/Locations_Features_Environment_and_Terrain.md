#### Locations, Features, Environment, and Terrain
When first describing the combat encounter, describe notable locations, objects, environmental features, and terrain features.
Write these down and keep them in front of the players if it helps them visualize the battlefield.
Let the players know that they can interact with these environmental features through such actions as swinging from magical chandeliers, climbing obsidian cliffs to advantageous positions, or taking cover behind ruined statues.
Update these features as the encounter changes.
A shattered object might stop providing cover, collapsing terrain might become difficult terrain, fire might spread, and the characters' or monsters' actions might create new hazards or opportunities.
If any feature or effect creates difficult terrain, let the players know how this might affect them, such as requiring that they use the Dash action to get out of the area.
If the players ask about an environmental detail that you haven’t mentioned or considered, you can add features that you hadn’t thought of if they make the encounter more interesting.
