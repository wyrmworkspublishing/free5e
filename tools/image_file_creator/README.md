Run from the free5e base directory with the following command:

```sh
python3 tools/image_file_creator/image_file_creator.py $LANGUAGE/$BOOK_NAME/images.csv en-US
```

Where `LANGUAGE` is the language of the book (e.g. `en-US`) and `BOOK_NAME` is the name of the book directory (e.g. `Characters_Codex`).
